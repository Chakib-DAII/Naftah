# ⚙️ الدوال (Functions) في لغة نفطه

هذا الملف يوضح كيفية **تعريف الدوال** في لغة **نفطه**، مع شرح مفصل لكيفية تحديد المعاملات النوعية، نوع القيمة المرجعة،
واستدعاء الدوال، بالإضافة إلى بعض الأمثلة العملية. كما يتناول موضوع الدوال ذات المعاملات الاختيارية، والقيم الافتراضية،
والدوال بدون قيمة مرجعة.

---

This file demonstrates how to **define functions** in the **Naftah** programming language, including detailed
explanation of **typed parameters**, return types, and how to **call functions**. It also covers optional parameters,
default values, and void functions.

---

## 🔄 العودية (Recursion) {#nla-recursion}

الـ **العودية** هي تقنية برمجية حيث تقوم الدالة باستدعاء نفسها ضمن تعريفها. تُستخدم العودية لحل مشاكل يمكن تقسيمها إلى
أجزاء أصغر تشبه المشكلة الأصلية.

### كيف تعمل العودية؟ {#nla-recursion-how-it-works}

* **حالة التوقف (Base Case):** شرط يوقف الاستدعاءات العودية لمنع الحلقات اللانهائية.
* **الاستدعاء العودي (Recursive Call):** الدالة تستدعي نفسها على نسخة مبسطة أو أصغر من المشكلة.

### لماذا نستخدم العودية؟ {#nla-recursion-why-use-it}

* تسهل كتابة الحلول لبعض المشاكل المعقدة مثل التعامل مع الهياكل الشجرية، والحسابات المتكررة، والتجميعات.
* تجعل الكود أكثر وضوحًا وأقرب إلى التفكير الرياضي أو المنطقي.

---

### 🧩 مثال: دالة المضروب (العامل) باستخدام العودية {#nla-factorial-example}

```naftah
--- دالة تحسب المضروب لعدد باستخدام العودية، مع قيمة افتراضية ١٠
دالة دالة_المضروب(عدد_مضروب تعيين 10) : عدد_طويل {
    --- شرط التوقف: إذا كان العدد ≤ ١، أرجع ١
    إذا عدد_مضروب أصغر_أو_يساوي ١ إذن {
        ارجع ١
    }
    أنهي

    --- الاستدعاء العودي: العدد × المضروب للعدد ناقص ١
    ارجع عدد_مضروب ضارب دالة_المضروب(عدد_مضروب ناقص ١)
}
```

## 🎯 استدعاءات الدالة مع شرح {#nla-factorial-calls}

```naftah
دالة_المضروب(5)  --- تحسب 5 × 4 × 3 × 2 × 1 = 120

دالة_المضروب(1)  --- حالة التوقف، تعيد 1 مباشرة

دالة_المضروب()   --- تستخدم القيمة الافتراضية 10 وتحسب 10! = 3628800
```

## 🧠 ملاحظات

* أسماء الدوال في نفطه عربية مع إمكانيات استخدامها مع الأرقام الصحيحة والعشرية.
* العمليات الحسابية والمنطقية تدعم الأعداد بمختلف أحجامها (8-بت، 16-بت، 32-بت، 64-بت، والأعداد العشرية).
* الدوال المضمنة تسهل كتابة كود واضح وقابل للقراءة بالعربية.
* الدوال تبدأ بكلمة `دالة` وتنتهي بـ `نهاية`.
* يمكن تحديد أنواع المعاملات باستخدام `: النوع`.
* يمكن تحديد نوع القيمة المرجعة بعد القوسين باستخدام `: نوع_القيمة`.
* المعاملات يمكن أن تكون اختيارية مع قيم افتراضية.
* الدوال التي لا ترجع قيمة لا تحتاج إلى تحديد نوع إرجاع أو يمكن اعتبارها `void`.
