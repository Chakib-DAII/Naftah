⚙️ الدوال (Functions) في لغة نفطه

هذا الملف يوضح كيفية تعريف الدوال في لغة نفطه، مع شرح مفصل لكيفية تحديد المعاملات النوعية، نوع القيمة المرجعة، واستدعاء الدوال، بالإضافة إلى بعض الأمثلة العملية. كما يتناول موضوع الدوال ذات المعاملات الاختيارية، والقيم الافتراضية، والدوال بدون قيمة مرجعة.

This file demonstrates how to define functions in the Naftah programming language, including detailed explanation of typed parameters, return types, and how to call functions. It also covers optional parameters, default values, and void functions.

🔄 العودية (Recursion)

الـ العودية هي تقنية برمجية حيث تقوم الدالة باستدعاء نفسها ضمن تعريفها. تُستخدم العودية لحل مشاكل يمكن تقسيمها إلى أجزاء أصغر تشبه المشكلة الأصلية.

كيف تعمل العودية؟

  • حالة التوقف (Base Case): شرط يوقف الاستدعاءات العودية لمنع الحلقات اللانهائية.
  • الاستدعاء العودي (Recursive Call): الدالة تستدعي نفسها على نسخة مبسطة أو أصغر من المشكلة.

لماذا نستخدم العودية؟

  • تسهل كتابة الحلول لبعض المشاكل المعقدة مثل التعامل مع الهياكل الشجرية، والحسابات المتكررة، والتجميعات.
  • تجعل الكود أكثر وضوحًا وأقرب إلى التفكير الرياضي أو المنطقي.

🧩 مثال: دالة المضروب (العامل) باستخدام العودية

--- دالة تحسب المضروب لعدد باستخدام العودية، مع قيمة افتراضية ١٠
دالة دالة_المضروب(عدد_مضروب تعيين 10) : عدد_طويل {
    --- شرط التوقف: إذا كان العدد ≤ ١، أرجع ١
    إذا عدد_مضروب أصغر_أو_يساوي ١ إذن {
        ارجع ١
    }
    أنهي

    --- الاستدعاء العودي: العدد × المضروب للعدد ناقص ١
    ارجع عدد_مضروب ضارب دالة_المضروب(عدد_مضروب ناقص ١)
}

🎯 استدعاءات الدالة مع شرح
